# 有迹（YouTrace）v1.0.3 实现与验收报告

本报告记录 2026-07-30 的实际实现和验证结果。它补充
[v1 验收标准](06-v1验收标准.md)，不降低原有发布门槛。

## 1. 结论

| 层级 | 状态 | 结论 |
|---|---|---|
| v1 功能实现 | `PREPARED` | FR-01 至 FR-23 均已有可运行实现和对应测试入口 |
| 自动化验证 | `VERIFIED` | 类型、构建、55 个单元/集成测试、25 个 Electron 流程、固定规模性能和文档链接检查通过 |
| 四条核心产品闭环 | `VERIFIED` | 课程、跨模块标签、永久努力记录和复盘调整均通过连续的真实 Electron E2E |
| 本机发布包 | `VERIFIED` | Setup、Portable 和解包版均在本机实际启动并创建 SQLite 工作区；Setup 卸载后外部工作区保留 |
| 整体 v1 发布 | `PREPARED` | 干净 Windows、真实移动盘、混合 DPI 多显示器、Narrator、原生通知和完整人工闭环尚未执行 |
| 用户验收 | 未进入 `ACCEPTED` | 需要用户确认首页、课程流程、标签聚合、迁移和整体体验 |

这里的“自动化验证 `VERIFIED`”只描述已经执行的证据层级，不等于整体版本已经达到
`VERIFIED`。依据验收标准，只要必需的真实环境人工项尚未完成，整体版本仍保持
`PREPARED`。

- 计划、日历、时间块、执行、努力更正和永久记录；
- 成果、附件、安全链接、备忘转换和来源保留；

### 4.3 真实 Electron 与发布包

`npm run test:electron` 的 25 个用例全部通过。Electron E2E 使用真实主进程、preload、
IPC 和 renderer，覆盖：

- 安全启动、CSP、外部导航拦截、IPC 输入校验、自绘窗口边缘缩放和隔离 API；
- 项目—任务—完成、日历容量与拖放、倒计时；
- 计时努力、备忘转换、习惯、指标和课程知识；
- 高级计划、保存搜索、学习记录、模板和复盘快照；
- 完整课程学习闭环：五个章节、不同任务属性、计时、备忘、真实证据文件、测试、掌握度、
  两种进度和考试倒计时，并在明确退出和重开后核对数据；
- 跨模块标签闭环：项目、任务、倒计时、备忘、努力和证据的聚合、统计、合并与关系去重；
- 永久努力记录闭环：两次计时、一次补录、更正、取消、回收站、项目历史和恢复；
- 复盘调整闭环：周计划、时间块、不可变快照以及分别顺延、拆分和取消未来任务；
- 备份验证、回收站恢复；
- 全部 11 个主导航页面的可读性扫描，以及浅色、深色和 125% 字号下的输入边界与布局；
- 自绘窗口最小化、最大化、还原、最小尺寸、关闭到后台，以及后台活动计时继续；
- 100%、125%、150%、200% 强制显示缩放下的核心导航可达和减少动画；
- 活动计时退出的取消与保留分支，以及重启后暂停而不计离线时间；
- 进程异常中断后的计时心跳冻结、恢复确认和离线时间排除；

输入框、文本域和下拉框具有可见边界且高度不低于 34px；同时固定验证设置页五个难度字段

统一提供边界，避免出现双重描边。

数据生成器版本为 `youtrace-scale-v1`，固定数据摘要为：

## 6. 数据安全结论

本次已经实际验证：

- 工作区根内相对路径解析，路径穿越被拒绝；
- 外部链接仅允许 `http`、`https` 和 `mailto`，危险协议被拒绝；
- 第二写实例被锁拒绝，显式只读连接可打开；
- 迁移采用校验后切换，源目录保留并写入迁移说明；
- 非空无效目标不被覆盖，活动工作区不切换；
- 恢复解包中断时继续使用源工作区；
- 工作区标识在运行中失联后停止写入、保留草稿，并拒绝同路径空目录；
- 原工作区重新出现或移动后，只按相同工作区 ID 和完整数据库恢复连接；
- 模拟 `ENOSPC`、`EACCES` 时迁移保留源工作区，并返回明确恢复提示；
- 迁移失败恢复状态跨重启保存，失败目标仅在身份标记匹配时允许清理；
- WAL 工作区备份可验证并恢复到独立目录；
- 自动备份按日/周/月分层保留，空间不足时不先删除现有已验证副本；
- 数据库损坏时保留只读副本并从已验证备份生成独立候选，确认前不切换；
- 异常中断计时不计离线时间，未提交长文本保存在工作区恢复区；
- 回收站永久删除不移除仍被其他对象引用的共享附件；
- 安装版卸载不删除用户选择的外部工作区。

本次没有在真实可移除磁盘上拔盘，也没有人为耗尽磁盘空间或修改系统 ACL。对应场景仍为
`PREPARED`。

6. 使用真实移动盘验证拔盘、重新定位和同路径空目录拒绝；另测空间不足和只读 ACL。

8. 使用键盘和 Windows Narrator 完成核心流程，检查焦点、名称、角色、状态、对比度和减少动态效果。
9. 由用户确认首页信息密度、浅色/深色主题、课程流程、标签聚合、迁移和整体长期使用体验。

## 8. 已知限制

- 发布包没有 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。
- v1 仅支持 Windows x64 和简体中文。
- v1 不含云同步、账户、多用户协作和 AI；工作区备份需要用户自行复制到其他介质。
- 本报告只证明当前代码和当前产物在所列环境中的结果；干净机和人工项不得从中推断为已通过。
