# 有迹（YouTrace）v1.0.0 实现与验收报告

本报告记录 2026-07-30 的实际实现和验证结果。它补充
[v1 验收标准](06-v1验收标准.md)，不降低原有发布门槛。

## 1. 结论

| 层级 | 状态 | 结论 |
|---|---|---|
| v1 功能实现 | `PREPARED` | FR-01 至 FR-23 均已有可运行实现和对应测试入口 |
| 自动化验证 | `VERIFIED` | 类型、构建、37 个单元/集成测试、13 个 Electron 流程、固定规模性能和文档链接检查通过 |
| 本机发布包 | `VERIFIED` | Setup、Portable 和解包版均在本机实际启动并创建 SQLite 工作区；Setup 卸载后外部工作区保留 |
| 整体 v1 发布 | `PREPARED` | 干净 Windows、移动盘失联、多显示器 DPI、Narrator、原生通知和完整人工闭环尚未执行 |
| 用户验收 | 未进入 `ACCEPTED` | 需要用户确认首页、课程流程、标签聚合、迁移和整体体验 |

这里的“自动化验证 `VERIFIED`”只描述已经执行的证据层级，不等于整体版本已经达到
`VERIFIED`。依据验收标准，只要必需的真实环境人工项尚未完成，整体版本仍保持
`PREPARED`。

## 4. 已执行的自动验证

### 4.1 编译与静态检查

| 命令 | 结果 |
|---|---|
| `npm run typecheck` | 通过 |
| `npm run build` | 通过；主进程、preload 和 renderer 生产构建完成 |
| `npm run dist:win` | 通过；生成 NSIS、Portable 和 `win-unpacked` |
| `npm run test:docs` | 通过；验证 9 份文档、34 个内部链接 |

### 4.2 单元和集成

`npm test` 结果为 15 个测试文件、37 个测试全部通过，覆盖：

- 等权、工作量、手动权重、掌握度覆盖率和父子进度；
- 任务依赖自环、环路、阻塞、跨项目关系和强制越过；
- 倒计时风险、自然日、工作日和静默时间；
- 工作区创建、打开、写锁和只读打开；
- 计划、日历、时间块、执行、努力更正和永久记录；
- 成果、附件、安全链接、备忘转换和来源保留；
- 习惯、指标、课程、知识点、错题、测试和复习；
- 模板、复盘不可变快照、批量调整和提醒；
- 备份—验证—恢复往返、回收站、导入导出；
- 根目录迁移保留源目录、无效目标不覆盖、恢复中断不切换源工作区。

### 4.3 真实 Electron 与发布包

`npm run test:electron` 的 13 个用例全部通过。Electron E2E 使用真实主进程、preload、
IPC 和 renderer，覆盖：

- 安全启动、自绘窗口边缘缩放和隔离 API；
- 项目—任务—完成、日历容量与拖放、倒计时；
- 计时努力、备忘转换、习惯、指标和课程知识；
- 高级计划、保存搜索、学习记录、模板和复盘快照；
- 备份验证、回收站恢复；
- 全部 11 个主导航页面的可读性扫描，以及浅色、深色和 125% 字号下的输入边界与布局；
- 解包版和最终 Portable EXE 的 SQLite 工作区创建；
- NSIS 安装、运行、卸载以及外部工作区保留。

可读性回归会检查当前可见的直接文本不低于 13px，普通输入控件文字不低于 16px，
输入框、文本域和下拉框具有可见边界且高度不低于 34px；同时固定验证设置页五个难度字段
在 125% 字号下保持同排，以及备忘速记框不会被标签操作行压缩。组合输入控件只允许由外层
统一提供边界，避免出现双重描边。

### 4.4 固定规模性能

数据生成器版本为 `youtrace-scale-v1`，固定数据摘要为：

- 10,000 个任务；
- 10,000 条备忘；
- 100,000 条努力记录；
- 5,000 个附件元数据；
- 100 个标签。

每项查询重复 20 次，本次结果如下：

| 操作 | 中位数 | P95 | 门槛 | 结果 |
|---|---:|---:|---:|---|
| 普通列表 | 20.12 ms | 20.64 ms | 500 ms | 通过 |
| 组合筛选 | 0.31 ms | 0.59 ms | 1,000 ms | 通过 |
| 中文全文检索 | 0.18 ms | 0.26 ms | 1,000 ms | 通过 |
| 月度努力汇总 | 139.37 ms | 154.98 ms | 2,000 ms | 通过 |

Release 解包版从进程启动到工作区首页可操作重复 20 次：

| 操作 | 中位数 | P95 | 门槛 | 结果 |

| 冷启动到首页 | 871.61 ms | 903.98 ms | 3,000 ms | 通过 |

这些数值是当前参考设备的本次结果，不应当解释为所有 Windows 设备的保证值。

## 6. 数据安全结论

本次已经实际验证：

- 工作区根内相对路径解析，路径穿越被拒绝；
- 外部链接仅允许 `http`、`https` 和 `mailto`，危险协议被拒绝；
- 第二写实例被锁拒绝，显式只读连接可打开；
- 迁移采用校验后切换，源目录保留并写入迁移说明；
- 非空无效目标不被覆盖，活动工作区不切换；
- 恢复解包中断时继续使用源工作区；
- WAL 工作区备份可验证并恢复到独立目录；
- 安装版卸载不删除用户选择的外部工作区。

本次没有在真实可移除磁盘上拔盘，也没有人为耗尽磁盘空间或修改系统 ACL。对应场景仍为
`PREPARED`。

## 7. 待人工验收清单

下面项目完成前，整体 v1 不进入 `VERIFIED`：

1. 在没有 Node.js、npm 和源码的干净 Windows 10/11 x64 普通用户环境，安装并卸载 NSIS，
   再直接运行 Portable。
2. 断网完成课程学习闭环、跨模块标签闭环、永久努力记录闭环和复盘批量调整闭环。
3. 验证文件夹选择、资源管理器打开、证据文件打开、浏览器链接和系统通知的原生行为。
4. 验证关闭到托盘、托盘恢复、通知唤醒、明确退出，以及活动计时的保存、保留和取消三条路径。
5. 验证睡眠恢复、跨静默时间和离线重启后的提醒去重汇总。
6. 使用真实移动盘验证拔盘、重新定位和同路径空目录拒绝；另测空间不足和只读 ACL。
7. 在 100%、125%、150%、200% 缩放及不同缩放的多显示器上验证拖动、四边四角缩放、
   Windows 贴靠、最大化和可见工作区恢复。
8. 使用键盘和 Windows Narrator 完成核心流程，检查焦点、名称、角色、状态、对比度和减少动态效果。
9. 由用户确认首页信息密度、浅色/深色主题、课程流程、标签聚合、迁移和整体长期使用体验。

## 8. 已知限制

- 发布包没有 Authenticode 签名，Windows SmartScreen 可能显示未知发布者提示。
- v1 仅支持 Windows x64 和简体中文。
- v1 不含云同步、账户、多用户协作和 AI；工作区备份需要用户自行复制到其他介质。
- 本报告只证明当前代码和当前产物在所列环境中的结果；干净机和人工项不得从中推断为已通过。
