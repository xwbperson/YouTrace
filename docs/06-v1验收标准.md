# 有迹（YouTrace）v1 验收标准

本文定义有迹 v1 从 `PREPARED` 进入 `VERIFIED` 和 `ACCEPTED` 所需的证据。功能入口存在、源码看起来完整或程序能够启动，都不能替代真实 Electron 流程、数据往返和异常恢复验证。

## 1. 验收状态

每个功能和发布包独立记录状态。

| 状态 | 进入条件 |
|---|---|
| `PREPARED` | 需求、设计、代码或测试已形成，但尚未运行对应验证 |
| `VERIFIED` | 已按本文完成自动或人工验证，并保存可复查证据 |
| `ACCEPTED` | 用户或产品负责人已确认功能和体验满足 v1 目标 |

不能用整体版本状态掩盖未验证模块。发布时需要列出仍为 `PREPARED` 的项目；存在 v1 必需项时不得宣布 v1 完成。

## 2. 验收环境

测试至少覆盖开发环境和打包环境。

- 当前受支持的 Windows 10 或 Windows 11 x64。
- NSIS 安装版。
- 便携版。
- 本地固定磁盘工作区。
- 可移除磁盘或模拟失联工作区。
- 普通用户权限，不依赖管理员运行。
- 断网状态。

依赖版本、Windows 版本、测试机器配置和安装包 SHA-256 必须记录在验收报告中。

## 3. 验收证据

每项验收需要与风险匹配的证据。

| 证据类型 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 类型检查和构建 | 代码可以编译 | 功能行为正确 |
| 单元测试 | 纯逻辑和边界条件正确 | Electron 集成正确 |
| 集成测试 | 数据库、文件和服务协作正确 | 界面流程可用 |
| Electron E2E | 真实窗口、preload、IPC 和主进程协作 | 安装版和便携版一定正确 |
| 打包冒烟 | 安装包和便携版能够运行 | 全部业务功能正确 |
| 人工验收 | 原生对话框、通知和整体体验可接受 | 回归可以长期自动发现 |

所有层级都通过后，关键功能才可以标记为 `VERIFIED`。

## 5. 核心产品闭环

下面的端到端场景是版本级验收，不允许拆成互不相连的页面演示。

### 5.1 课程学习闭环

在新的真实工作区中完成以下流程。

1. 创建“计算机网络”课程项目并填写官方教材。
2. 创建至少五个章节里程碑。
3. 为章节添加阅读、笔记、习题、测试和复盘任务。
4. 为任务设置不同难度、预计时间、优先级和标签。
5. 使用计时器完成一项任务并添加笔记和证据文件。
6. 完成章节测试并记录掌握度。
7. 分别查看等权进度和工作量进度。
8. 创建考试倒计时并查看建议学习速度。
9. 通过托盘明确退出程序并重新打开，确认全部数据一致。

验收结果需要证明执行进度和掌握度可以不同，切换主进度模式不会改写原始数据。

### 5.2 跨模块标签闭环

标签需要跨对象工作，而不是只在任务列表中生效。

1. 创建自定义标签“计算机网络”。
2. 把标签添加到项目、任务、倒计时、备忘、努力记录和证据。
3. 打开标签聚合页。
4. 验证各类对象、投入时间、难度分布和风险汇总。
5. 把该标签与另一个标签合并。
6. 验证关系去重且没有业务对象被删除。

### 5.3 永久努力记录闭环

努力事实必须在结构变化后仍可追踪。

1. 对任务记录两次计时和一次手动补录。
2. 更正其中一次时间并查看修改历史。
3. 取消任务，再把任务移入回收站。
4. 在努力账本和项目历史报表中查看三次投入。
5. 恢复任务，确认关系和原任务快照一致。

### 5.4 成果证据管理闭环

1. 分别创建文件、图片、链接、文本笔记、成绩和外部反馈成果。
2. 验证六种类型都显示点击与拖拽附件入口；文件和图片没有附件时不能保存。
3. 为文本笔记附加一个真实文件，验证原文件未移动、工作区生成副本且来源链接仍保留。
4. 编辑成果的标题、说明、验证状态和关联任务，并追加一个附件。
5. 删除成果，验证普通列表不再显示，回收站显示成果名称和附件数量。
6. 从回收站恢复成果，验证正文、验证状态、关系和附件均可继续查看。
7. 永久删除前验证已验证备份门槛；共享附件保留，独占附件才允许清理。

### 5.5 复盘调整闭环

复盘需要保留原计划并产生可执行的新计划。

1. 建立一周计划并安排时间块。
2. 完成部分任务，延期部分任务并记录原因。
3. 生成周复盘。
4. 批量顺延、拆分和取消未完成任务。
5. 验证复盘快照仍显示调整前计划。
6. 验证新任务和日期进入下一周。
7. 完成复盘后，验证页面只展示正文，不显示输入框、“保存草稿”和“完成复盘”。
8. 点击“编辑复盘”，修改并保存正文，验证状态仍为已完成且原快照不变。
9. 删除复盘，验证普通复盘列表不再显示、回收站可见且已执行的任务调整没有撤销。
10. 从回收站恢复复盘，验证正文、完成状态和原快照均可继续查看。
11. 验证“编辑复盘”和“删除复盘”的按钮文字使用同一字号。

## 6. 进度计算验收

进度算法需要用固定数据集验证。

准备三个章节：

| 章节 | 内部进度 | 工作量权重 |
|---|---:|---:|
| 第一章 | 100% | 1 |
| 第二章 | 50% | 2 |
| 第三章 | 0% | 7 |

预期结果为：

- 等权进度为 50%。
- 工作量进度为 20%。
- 切换主显示模式后两个结果不变。
- 难度从 1 改为 5 后两个进度不变。
- 修改第二章工作量权重后，仅工作量进度变化。

掌握度测试需要包含未评估章节，确认未评估不会被当作 0 分，界面同时显示评估覆盖率。

## 7. 任务逻辑验收

任务规则需要覆盖正常路径和边界。

- 子任务完成能按权重更新父任务。
- “仅参考”子任务不进入分母。
- 检查清单只有在选择对应模式时参与进度。
- 任务不能依赖自身。
- A 依赖 B、B 依赖 C 时，不能再创建 C 依赖 A。
- 前置任务未完成时显示阻塞来源。
- 强制越过依赖需要记录原因。
- 跨项目依赖显示来源项目，但不传播完成进度。
- 前置项目进入回收站后，后续任务保持阻塞并显示原因。
- 恢复前置项目后，依赖关系恢复正常。
- 永久删除前置任务前，系统要求解除或替换跨项目依赖。
- 周期规则修改不改变已经完成的实例。
- 停止计时不自动完成任务。
- 完成任务不自动把证据升级为已验证。

## 8. 工作区验收

工作区测试以 [工作区与数据安全](05-工作区与数据安全.md) 为依据。

### 8.1 创建和重新打开

创建工作区后需要验证标记、目录、数据库和启动指针。删除启动指针后，使用“打开已有工作区”仍能恢复全部业务数据。

### 8.2 相对路径迁移

分别通过点击选择和拖拽导入多个附件，确认原文件未移动、工作区内出现复制文件且业务对象
关联成功。复制整个工作区到不同盘符，打开副本时，附件、证据和缩略图都应正常访问，
数据库中不得出现旧盘符业务路径。

### 8.3 根目录迁移

迁移测试需要覆盖：

- 迁移成功并切换到目标目录。
- 目标空间不足。
- 目标目录只读。
- 复制过程中断。
- 校验失败。
- 目标数据库无法打开。

所有失败场景都必须继续使用源工作区，且源目录不被删除。

### 8.4 工作区失联

在程序打开时模拟移动盘断开。程序需要停止写入、保留可复制草稿、提示重新定位，并拒绝把同路径的新空目录当作原工作区。

### 8.5 单实例锁

同时启动两个实例打开同一工作区。第二个实例不能获得写锁，并需要提供返回或只读打开选项。

## 9. 备份和恢复验收

备份成功必须以可恢复为标准，而不是以文件存在为标准。

1. 在持续使用过 WAL 的工作区中创建备份。
2. 向原工作区继续写入新数据。
3. 把备份恢复到临时工作区。
4. 验证备份时间点的数据库记录、附件和证据文件。
5. 验证备份后的新数据不混入恢复结果。
6. 模拟恢复中断，确认原工作区没有被部分覆盖。

至少保留一个自动化备份—恢复往返测试。

## 10. 回收站验收

回收站需要同时验证数据库关系和物理文件。

- 删除带附件的任务后，普通页面不再显示任务。
- 努力账本仍可显示历史投入。
- 物理文件进入回收区域或保持受保护引用。
- 恢复任务后，附件和关系重新可用。
- 删除复盘后，正文和快照一起进入回收站；恢复后两者重新可用。
- 永久删除复盘会清除正文、快照和调整记录，但不回滚已经执行的任务调整。
- 共享附件仍被其他对象使用时，永久删除不能移除物理文件。
- 原父对象不存在时，恢复内容进入“已恢复内容”。

## 11. 搜索和性能验收

搜索需要使用接近目标规模的生成数据验证正确性和响应时间。

参考数据至少包括：

- 10,000 个任务。
- 100,000 条努力记录。
- 10,000 条备忘。
- 5,000 个附件元数据。
- 100 个标签和大量跨类型关联。

需要验证全文搜索、多个标签交集、日期范围、难度、状态和项目组合筛选。性能目标以 [产品需求文档](01-产品需求文档-PRD.md#113-性能目标) 为准。

全文搜索需要分别覆盖中文连续文本、中英文混合、三个及以上字符、一个或两个字符、标点和无结果查询。删除或重建搜索索引后，结果必须能从业务表完整恢复，且不能把软删除对象显示为普通结果。

性能数据由固定随机种子的脚本生成，并记录生成器版本和数据摘要。冷启动、列表、搜索和汇总各至少重复 20 次；测试记录参考设备、Release 构建、测量起止点、中位数和 P95，P95 不得超过对应目标。

## 12. Electron 安全验收

安全检查需要同时检查配置和可观察行为。

- Renderer 的 `process`、`require` 和任意文件系统能力不可用。
- `contextIsolation` 和 sandbox 在真实窗口中启用。
- Preload 只暴露命名 API，不暴露原始 `ipcRenderer`。
- 非法 IPC 输入返回统一错误，不到达 repository。
- 路径穿越和根目录外路径被拒绝。
- 未授权导航、新窗口和外部协议被阻止。
- CSP 不允许远程脚本和任意内联执行。
- Markdown 原始 HTML、脚本、危险协议和远程嵌入内容被阻止，普通文本、代码块和允许协议链接正常显示。

## 13. Windows 打包验收

安装版和便携版都需要在没有开发依赖的 Windows 环境测试。

- 安装、启动、退出和卸载行为正确。
- 便携版不需要安装即可启动。
- 原生 SQLite 模块在两个包中都能创建、写入、查询和备份。
- 系统通知显示正确名称和图标。
- 文件夹选择、资源管理器打开和外部链接行为正确。
- 主窗口不显示原生 Windows 标题栏、边框或原生窗口控制。
- 真实窗口配置为 `frame: false`、`thickFrame: false` 和 `transparent: false`。
- 自绘最小化、最大化、还原、关闭、拖动和双击标题栏行为正确。
- 窗口边缘与四角缩放、Windows 贴靠、最小尺寸和最大化到当前显示器工作区行为正确。
- 在 100%、125%、150%、200% 缩放和不同缩放比例的多显示器之间移动后，窗口仍位于可见工作区。
- 开发版和发布包的托盘图标均可见。
- 设置为“最小化到托盘”时关闭主窗口会隐藏窗口且计时与提醒继续；托盘恢复和通知唤醒后窗口获得焦点，托盘“退出”能够真正结束进程。
- 设置为“直接退出程序”时关闭主窗口会走明确退出流程，退出后不保留后台进程。
- 切换窗口焦点不触发整窗透明、模糊、闪烁或内容失焦。
- 卸载默认不删除外部工作区。

明确退出、睡眠和跨静默时间需要分别验证：退出期间不承诺即时通知，再次启动后只显示去重汇总；睡眠恢复后不重复触发同一提醒；静默时间内的提醒按用户设置延后或进入汇总。

活动计时期间通过托盘退出，需要分别验证保存到当前时刻、保留未结束会话和取消退出；任何路径都不能丢失已记录投入，也不能把退出后的离线时间静默计入努力。

打包冒烟通过后仍需运行课程学习闭环的关键子集。

## 14. 可用性与可访问性验收

主要页面需要按 WCAG 2.2 AA 基线完成键盘、对比度和辅助技术检查。

- 不使用鼠标可以创建任务、开始计时、保存备忘和打开搜索。
- 不使用鼠标可以选择标签、操作对话框和使用自绘窗口控制。
- 焦点顺序与视觉顺序一致。
- 状态、风险和难度不只依赖颜色。
- 普通文本对比度不低于 4.5:1，大文本和图形控件不低于 3:1。
- 100%、125%、150%、200% 系统缩放下没有核心内容不可达。
- 使用 Windows Narrator 检查核心流程的名称、角色、状态和焦点变化。
- 深色和浅色主题符合 [功能设计](02-功能设计.md#21-视觉主题) 的颜色、字体和轨迹线规范。
- 系统启用减少动态效果时，不播放位移和缩放动画。
- 空状态、加载、成功、失败和只读状态都有明确反馈。
- 字段错误使用内联提示，破坏性操作和工作区错误使用对应的阻塞反馈。

日期时间测试至少覆盖仅日期事项、具体时刻、工作区时区变更和一个夏令时切换时区。仅日期事项不能偏移日期，已完成记录不能因时区变更改写，周期实例不能重复生成。

## 15. 发布门槛

以下条件全部满足后，v1 才能标记为 `VERIFIED`。

- FR-01 至 FR-23 没有缺失实现。
- 核心产品闭环全部通过真实 Electron E2E。
- 根目录迁移、备份恢复、回收站和异常退出测试通过。
- 安装版和便携版通过干净 Windows 验收。
- 没有导致数据丢失、错误覆盖或越界文件访问的已知问题。
- 没有把浏览器预览或启动冒烟当作功能完成证据。
- 所有文档内部链接有效，术语和默认值与实现一致。
- 发布产物具有 SHA-256、版本说明和已知限制清单。

`ACCEPTED` 需要在 `VERIFIED` 之后，由用户确认首页、课程流程、标签聚合、数据迁移和整体使用体验符合预期。

## 16. 验收记录模板

每次验收使用统一记录，避免只写“测试通过”。

| 字段 | 内容 |
|---|---|
| 功能编号 | 例如 FR-09 |
| 场景 | 等权与工作量进度 |
| 环境 | Windows、安装包、工作区位置 |
| 前置数据 | 固定数据集或工作区快照 |
| 操作步骤 | 可重复的实际步骤 |
| 预期结果 | 明确数值或行为 |
| 实际结果 | 实际观察和文件证据 |
| 状态 | PREPARED / VERIFIED / ACCEPTED |
| 证据 | 测试日志、截图、视频或备份包 |
| 限制 | 未覆盖范围和已知风险 |
