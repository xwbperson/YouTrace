# 有迹（YouTrace）v1.0.7 发布说明

## 1. 版本概览

有迹 v1.0.7 是面向 Windows x64 的本地优先个人执行与努力记录桌面应用。它把领域、项目、
目标、计划、任务、日历、计时、努力记录、成果、备忘、习惯、指标、课程学习、复盘、提醒和
数据管理放在同一个可迁移工作区中。

本版本默认离线运行，不需要账户，不上传业务数据。业务数据库和附件均保存在用户选择的
工作区根目录。

## 2. 发布文件

- `YouTrace-1.0.7-Setup.exe`：Windows NSIS 安装版，可选择安装目录。
- `YouTrace-1.0.7-Portable.exe`：免安装便携版。
- `SHA256SUMS.txt`：两个 EXE 的 SHA-256 校验值。

校验示例：

```powershell
Get-FileHash .\YouTrace-1.0.7-Setup.exe -Algorithm SHA256
Get-FileHash .\YouTrace-1.0.7-Portable.exe -Algorithm SHA256
```

实际哈希见仓库首页和发布附件 `SHA256SUMS.txt`。

## 3. 核心功能

- 工作区创建、打开、切换、只读打开、迁移、检查、备份和恢复；
- 领域、项目、目标、里程碑、父子任务、清单、依赖、周期和回收站；
- 年、季度、月、周、日计划，以及日/周/月日历、时间块和容量提示；
- 今日三件重点、计时、补录、更正历史、暂停与恢复；
- 项目历史报表，在任务取消、回收和恢复后仍保留投入快照与变更轨迹；
- 等权、工作量、手动权重、掌握度、倒计时速度、缓冲和风险；
- 成果文件与链接、验证状态、快速备忘、来源关联和内容转换；
- 跨模块标签、预设标签、自定义标签、合并、筛选和保存视图；
- 习惯、指标、课程、教材章节、知识点、错题、测试和复习队列；
- 每日、每周、每月复盘，不可变快照和批量顺延、拆分、取消；
- 截止、复习、停滞、过载和静默提醒；
- 浅色/深色主题、字体、密度、关闭行为、备份与通知设置；
- 可见输入边界、16px 表单文字、最小辅助字号和 125% 字号布局回归；
- 五个内置项目模板和自定义模板。

相较 v1.0.6，本补丁版本强化了每日执行选择、课程资料管理和失败状态反馈：

- 今日重点改为用户明确选择的每日列表，最多三项，支持排序、移除和跨页面同步；
- 已完成、取消或删除的任务会自动退出当日重点，其他重点顺序保持不变；
- 课程学习支持一门课程关联多个资料条目，资料可附加多个文件并从课程快速筛选；
- 首页、今日、计划、日历、记录、备忘、复盘、标签、模板、设置和数据管理补齐加载失败、重试和操作失败提示；
- 任务清单、依赖和周期设置不再静默忽略失败结果；
- 开发启动会在进入 Electron Vite 前检查 Electron 是否完整安装，以便给出更直接的安装失败信息。

## 4. 首次使用

1. 启动应用，选择“创建工作区”。
2. 选择一个有足够空间、可长期保存且会定期备份的目录。
3. 先创建领域或项目，再建立目标、任务与本周计划。
4. 在“数据中心”创建第一个手动备份，并把备份复制到另一块磁盘。

不要把工作区放在会被清理的临时目录中。移动整个工作区时应使用应用内迁移功能，或在应用
完全退出后复制整个根目录。

## 5. 已知限制

- 当前 EXE 没有 Authenticode 数字签名，Windows SmartScreen 可能显示未知发布者。
- 仅支持 Windows x64 和简体中文。
- 不提供云同步、账户、多人协作或 AI 功能。
- 运行中工作区失联与同 ID 重连已有自动回归；真实移动盘、混合 DPI 多显示器、
  Windows Narrator 和真实系统通知仍需按
  [v1 人工验收清单](09-v1人工验收清单.md) 检查。
- 卸载应用默认保留外部工作区；如需删除数据，应先确认备份，再由用户自行处理工作区目录。
