# 有迹（YouTrace）v1 功能设计

本文把 [产品需求文档](01-产品需求文档-PRD.md) 转换为可设计、可实现和可验收的页面与行为。界面应优先展示下一步、真实投入和期限风险，同时允许用户逐步使用高级字段。

## 1. 信息架构

主导航按使用频率组织，而不是按数据库实体组织。

| 一级入口 | 主要内容 |
|---|---|
| 首页 | 今日重点、倒计时、项目风险、本周投入、快速记录 |
| 今日 | 今日时间轴、待办、正在进行、专注计时 |
| 计划 | 领域、项目、目标、里程碑、任务、习惯和指标 |
| 日历 | 日、周、月视图和时间块 |
| 记录 | 努力账本、成果证据和活动时间轴 |
| 备忘 | 收件箱、普通备忘、知识点、错题和归档 |
| 复盘 | 每日、每周、每月复盘 |
| 更多 | 标签、模板、保存视图、回收站和设置 |

全局顶栏提供工作区名称、全文搜索、快速创建、当前计时和通知入口。

## 2. 通用对象能力

目标、项目、里程碑、任务、习惯、指标、倒计时、备忘、努力记录和成果证据共享一组基础交互。

- 使用稳定 ID 标识，不依赖名称或文件路径。
- 支持创建时间、修改时间、归档时间和软删除时间。
- 支持多个可选标签。
- 支持收藏、备注和关联对象。
- 支持活动历史，记录关键字段的变化。
- 支持从详情页打开相关项目、任务、记录和证据。

通用详情页由标题区、核心字段、关联内容、活动历史和危险操作区构成。

## 3. 首页

首页让用户在启动后直接决定行动，不要求先整理全部项目。

默认模块包括：

- 三个最近且重要的倒计时。
- 今日最重要的一件事和三个重点任务。
- 当前计时及今日时间轴。
- 本周每日投入柱状图。
- 处于注意或危险状态的项目。
- 最近成果和快速备忘。

用户可以调整模块顺序和显隐。隐藏模块不影响数据和后台提醒。

## 4. 领域、项目和目标

领域用于长期分类，项目用于承载一段明确工作，目标用于定义结果。

### 4.1 领域

领域包含名称、颜色、图标、说明和归档状态。系统可预设学习、健身、编程、读书、工作、生活、健康和财务，但用户可以修改或删除预设。

### 4.2 项目

项目包含所属领域、名称、说明、状态、起止日期、主标签、封面、成功标准和默认进度模式。项目状态为计划中、进行中、暂停、完成、取消和归档。

项目详情提供总览、里程碑、任务、日历、记录、成果、备忘和复盘页签。

### 4.3 目标

目标可以属于项目，也可以作为独立目标存在。目标必须允许填写成功标准、目标日期、衡量方式和当前状态。

衡量方式支持：

- 里程碑完成度。
- 数值指标。
- 累计工作量。
- 人工确认。

## 5. 里程碑和任务

里程碑承载阶段成果，任务承载下一步行动。

### 5.1 里程碑

里程碑包含名称、说明、所属目标或项目、计划日期、实际完成日期、预计工作量、权重、验证标准和状态。课程章节是里程碑的一种模板，不是单独的数据孤岛。

里程碑状态为未开始、进行中、已完成、已验证、已认可、暂停和取消。

### 5.2 任务

任务包含以下字段：

| 字段 | 规则 |
|---|---|
| 标题 | 必填，表达一个可执行动作 |
| 所属对象 | 可关联项目、目标或里程碑 |
| 状态 | 收件箱、待安排、已安排、进行中、阻塞、已完成、已取消 |
| 难度 | 1 至 5 级，可为空 |
| 优先级 | 低、中、高、关键 |
| 预计时间 | 以分钟保存，可为空 |
| 实际时间 | 从努力记录自动汇总，不直接覆盖 |
| 开始与截止 | 可设置日期或具体时间 |
| 进度权重 | 工作量模式下使用，默认由预计时间推导 |
| 验证标准 | 可为空，关键任务建议填写 |
| 标签 | 可选、多选 |

难度的默认名称为轻松、简单、中等、困难和挑战。用户可以在设置中修改显示名称，但内部值保持 1 至 5。

### 5.3 子任务和检查清单

子任务拥有完整任务字段，可以继续包含子任务。检查清单只保存文本、顺序和勾选状态，适合不需要独立计划的步骤。

父任务进度默认由纳入计算的直接子任务汇总。用户可以把子任务标记为“仅参考”，使其不参与进度。

### 5.4 任务依赖

任务支持“完成后才能开始”的依赖关系。系统禁止任务依赖自身，并阻止形成依赖环。

前置任务未完成时，后续任务显示阻塞来源。用户仍可强制开始，但系统需要记录覆盖原因。

### 5.5 周期任务

周期规则支持每日、每周、每月、指定星期和自定义间隔。每次发生都生成独立任务实例，完成或跳过一个实例不能修改历史实例。

## 6. 难度、工作量、优先级和紧迫度

四个属性分别回答不同问题，界面不能把它们合并成一个分数。

| 属性 | 回答的问题 | 是否参与进度 |
|---|---|---|
| 难度 | 完成它需要多强的认知或体力投入 | 否 |
| 工作量 | 预计需要多少时间或份额 | 是 |
| 优先级 | 对目标结果有多重要 | 否 |
| 紧迫度 | 距离期限还有多久 | 否，参与风险提示 |

系统可以提示“某天高难度任务过多”，但不能因为任务困难就自动提高完成百分比。

## 7. 计划、日历和今日执行

计划模块负责选择承诺，日历负责安排时间，今日页负责执行。

### 7.1 多层计划

年、季度、月、周、日计划都引用现有目标或任务，不复制业务对象。每个周期支持重点结果、可用时间、承诺事项和复盘入口。

### 7.2 时间块

时间块包含开始、结束、关联任务和计划说明。拖动时间块只改变安排，不改变任务截止日期。

系统按每日可用时间比较计划时长，并提示超载、高难度任务集中和时间冲突。

### 7.3 今日执行台

今日页提供：

- 今日最重要的一件事。
- 最多三个重点任务。
- 已安排时间块和未安排待办。
- 当前计时器。
- 快速完成、延期、阻塞和转明日操作。
- 当日实际投入和剩余容量。

任务开始计时后进入“进行中”。停止计时不自动完成任务，用户需要确认结果或保持进行中。

用户通过托盘明确退出且存在活动计时时，必须选择“保存到当前时刻并停止”“保留为未结束会话”或“取消退出”。程序不能静默丢弃记录，也不能在下次启动时自动把整个离线时段计入努力。

## 8. 努力账本和成果证据

努力账本保存事实，成果证据支持验证。

### 8.1 努力记录

努力记录可以来自计时器或手动补录，字段包括开始时间、结束时间、有效时长、关联对象、难度感受、精力、结果、中断、困难、下一步和标签。

用户可以更正误记时间，但系统保留修改历史。删除关联任务后，记录仍存在，并显示原任务快照。

### 8.2 成果证据

成果证据支持文件、图片、链接、文本笔记、成绩和外部反馈。每项证据包含来源、创建时间、验证状态和关联对象。

证据状态为已准备、已完成、已验证和已认可。状态升级需要明确操作，完成任务不能自动升级证据。

## 9. 进度计算

系统同时保存原始事实和计算结果，计算结果可以重建。

### 9.1 里程碑内部进度

没有子任务时，里程碑状态决定基础进度。存在纳入计算的任务时，里程碑按任务权重汇总。

```text
里程碑进度 = Σ（任务完成比例 × 任务权重）÷ Σ任务权重
```

任务没有显式权重时，优先使用预计时间；没有预计时间时使用权重 1。

### 9.2 等权进度

等权模式让每个纳入计算的里程碑占相同比例。

```text
项目等权进度 = Σ里程碑进度 ÷ 纳入计算的里程碑数量
```

该模式适合章节规模接近的教材。

### 9.3 工作量进度

工作量模式按预计时间或手动权重汇总。

```text
项目工作量进度 = Σ（里程碑进度 × 里程碑权重）÷ Σ里程碑权重
```

用户可以选择等权进度或工作量进度作为主显示模式，另一个模式始终可在详情中查看。

### 9.4 掌握度

掌握度独立于执行进度，取值为 0 至 100 或未评估。课程可按章节权重汇总掌握度，但未评估章节不能被当作 0 分静默拉低结果。

界面需要明确显示类似结果：

```text
执行进度 100% · 掌握度 72% · 状态：需要复习
```

## 10. 倒计时

倒计时既可以独立存在，也可以关联目标、里程碑、任务、习惯、指标或外部事件。

倒计时包含标题、目标时间、工作日规则、缓冲天数、重要程度、标签和关联对象。系统显示自然日、有效工作日、剩余工作量、建议速度和预计完成日期。

风险状态为正常、注意、危险和逾期。风险根据剩余时间、剩余工作量、近期实际速度和缓冲计算，用户可以查看触发原因。

## 11. 备忘录

备忘录先帮助用户捕捉，再帮助用户整理。

备忘类型包括普通备忘、知识点、问题、错题、灵感和会议记录。新建内容可以只填正文，其余字段均可后补。

备忘支持：

- 收件箱和归档。
- Markdown 文本、附件和链接；附件可点击选择或拖入，导入时复制到当前工作区。
- 关联项目、里程碑、任务或教材章节。
- 转换为任务、知识点或错题。
- 保留转换前的原始内容和来源关系。
- 已归档备忘可在明确确认后永久删除；删除不可恢复，但不会连带删除已经转换出的对象或已保存附件。

## 12. 标签

标签是全局横向关系，所有主要业务对象都使用同一套标签。

标签包含名称、颜色、图标、说明、排序、常用状态和归档状态。系统提供学习、健身、编程、读书等可编辑预设。

标签功能包括：

- 创建、重命名、归档和删除。
- 合并重复标签。
- 多选添加和批量移除。
- 按标签查看任务、倒计时、备忘、记录和成果。
- 汇总投入时间、完成数量、难度分布和近期风险。

删除标签只解除关系，不删除任何业务对象。

## 13. 习惯和指标

习惯记录重复行为，指标记录数值变化。

习惯支持重复规则、目标次数、提醒、完成、跳过和跳过原因。连续天数只是反馈，不能覆盖总完成次数和真实历史。

指标包含名称、目标值、单位、方向、周期和记录值。例如页、章、小时、公里、千克和次数。系统显示累计值、趋势和距离目标的差额。

## 14. 学习功能

学习模块是在通用项目模型上的领域化视图。

课程包含官方教材信息、章节里程碑、知识点、错题、测试、复习队列和考试倒计时。章节模板默认包含阅读、笔记、习题、测试和复盘任务，用户可以修改模板。

复习队列支持手动指定日期和基于最近复习结果生成下一次日期。v1 使用确定性规则，不使用 AI 判断掌握情况。

## 15. 复盘

复盘保存当时的计划、事实和决定，后续修改不能重写快照。

每日复盘包含重要成果、实际投入、未完成事项、阻塞和明日第一步。每周和每月复盘增加计划对比、标签投入、延期原因、成果清单和下一周期承诺。

复盘完成后可以批量顺延、拆分、取消或重新安排任务。每次调整保存原因和前后值。

草稿保持可编辑，并显示“保存草稿”和“完成复盘”。完成后的复盘默认进入只读展示态，不再显示这两个操作；用户点击“编辑复盘”后才能修改复盘正文，保存修改不会重写原始快照，也不会把状态退回草稿。

复盘支持软删除和从回收站恢复。删除复盘会同时隐藏正文和原始快照，但不会撤销已经执行的任务调整；永久删除会清除复盘正文、快照和调整记录。

## 16. 搜索和保存视图

搜索结果需要跨模块展示，并允许用户快速回到来源。

组合筛选支持对象类型、状态、标签、日期、难度、优先级、项目、是否逾期和是否有证据。用户可以保存筛选条件为命名视图。

系统预设以下整理视图：

- 高优先级且逾期的任务。
- 本周到期的高难度任务。
- 长期没有行动的项目。
- 没有标签的内容。
- 没有下一步的进行中项目。
- 待处理备忘和待复习内容。

## 17. 提醒

提醒帮助用户及时行动，但不能制造持续打扰。

提醒来源包括截止日期、时间块、倒计时、周期任务、复习、项目停滞和计划超载。用户可以设置全局静默时间、按标签关闭提醒、延后提醒和关闭单项提醒。

系统通知点击后应打开对应对象。提醒失败不能影响对象本身的数据。

用户可以在设置中选择关闭主窗口时“最小化到托盘”或“直接退出程序”。默认最小化到托盘，后台计时和提醒继续运行；托盘提供“打开有迹”和“退出”。选择直接退出或从托盘明确退出时，界面说明后台任务将停止。再次启动或从休眠恢复后，系统按静默规则汇总错过的提醒，不能一次弹出大量重复通知。

## 18. 模板

模板批量创建结构，但不复制历史记录。

v1 内置课程学习、阅读一本书、开发一个程序、健身训练和考试准备模板。用户可以从现有项目结构保存自定义模板，并在创建前预览将生成的对象。

## 19. 回收站

删除操作默认进入工作区回收站，危险操作需要明确确认。

回收站支持查看来源、删除时间、影响范围、恢复和永久删除。恢复时如果原父对象不存在，内容进入“已恢复内容”区域并提示重新归属。

## 20. 设置

设置页面按影响范围分组。

| 分组 | 设置内容 |
|---|---|
| 工作区与数据 | 根目录、打开、迁移、检查、备份、恢复、存储占用 |
| 计划与时间 | 工作区时区、工作日、每日容量、一周起始日、默认时长 |
| 难度与状态 | 难度显示名称、默认优先级、完成确认 |
| 标签 | 预设、颜色、图标、合并和归档 |
| 通知与后台 | 全局开关、静默时间、默认提前量，以及“最小化到托盘/直接退出程序”关闭行为 |
| 外观 | 浅色、深色、跟随系统、字号和紧凑度 |
| 数据维护 | 回收站、日志、完整性检查、导入和导出 |

根目录的创建、打开和迁移行为以 [工作区与数据安全](05-工作区与数据安全.md) 为准，设置页面不能绕过其中的校验和回滚流程。

## 21. 视觉主题

有迹采用“冷静工作台 + 轨迹线”的视觉语言。界面通过清晰层级和连续轨迹表现努力积累，不使用玻璃拟态、Acrylic、Mica、透明窗口或大面积渐变。

### 21.1 主题颜色

浅色和深色主题使用同一套语义令牌，强调色不能替代状态文字。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| Canvas | `#F3F6F5` | `#101614` | 主背景 |
| Surface | `#FFFFFF` | `#18201E` | 面板和弹层 |
| Ink | `#17201E` | `#E9EFED` | 主文本 |
| Muted | `#5D6B67` | `#AAB7B2` | 次要文本 |
| Trace | `#216E65` | `#6FC2B3` | 主操作和进度轨迹 |
| Time | `#B95D1B` | `#F1A85A` | 倒计时和时间提醒 |
| Border | `#D8E1DE` | `#2B3834` | 分隔线和输入框 |
| Danger | `#B63E3E` | `#FF8585` | 破坏性操作和危险状态 |

`Time` 浅色值只用于图标、边框或具有足够对比度的文字。图表需要同时提供文字、图例或纹理，不能只依靠颜色区分。

### 21.2 字体与数字

v1 不加载网络字体，优先使用 Windows 自带字体。

- 标题使用 `Segoe UI Variable Display`，依次回退到 `Segoe UI`、`Microsoft YaHei UI` 和 `system-ui`。
- 正文和控件使用 `Segoe UI Variable Text`，依次回退到 `Segoe UI`、`Microsoft YaHei UI` 和 `system-ui`。
- 倒计时、时长和统计数字优先使用 `Bahnschrift`，缺失时回退到正文栈。
- 正文基准字号为 14px，说明文字不低于 12px，主要数字使用 24px 至 32px。

### 21.3 布局与组件

桌面布局保持紧凑，减少重复卡片。

- 自绘标题栏高度为 44px。
- 左侧主导航默认宽度为 232px，可折叠。
- 主内容使用 8px 间距网格和最多 12 列布局。
- 详情页可显示 320px 的右侧检查器，窄窗口中改为抽屉。
- 普通组件圆角为 8px，主要面板圆角为 12px。
- 阴影只用于菜单、对话框和拖动中的对象，常驻面板使用边框区分。

界面的标志性元素是“轨迹线”：项目、课程和努力记录页使用一条连续纵向线连接里程碑、投入和成果。轨迹线表达真实先后关系，不作为无意义装饰。

### 21.4 动效

动效只用于解释状态变化。

- 普通过渡持续 140 至 220 毫秒。
- 任务完成时只更新轨迹节点和局部进度，不播放全屏庆祝动画。
- 拖放、展开和进度变化需要保持空间连续性。
- 系统启用减少动态效果时，关闭位移和缩放动画，只保留必要的颜色或显隐变化。

## 22. 自绘窗口

主窗口使用自绘标题栏和窗口控制，避免原生 Windows 标题栏参与视觉和焦点状态。

- 标题栏背景始终不透明，不使用背景模糊和整窗透明度。
- 可拖动区域使用 `app-region: drag`，按钮、输入框和标签使用 `no-drag`。
- 双击空白标题栏切换最大化与还原。
- 最小化、最大化、还原和关闭按钮具有文字替代、键盘焦点和明确悬停状态。
- 窗口支持边缘和四角缩放、Windows 贴靠、最大化到当前显示器工作区，并设置保证核心导航可用的最小尺寸。
- 在不同缩放比例的多显示器之间移动或从托盘、系统通知恢复时，窗口保持在可见工作区并获得正确焦点。
- 窗口失去焦点时只降低标题和控制按钮的强调度，不改变内容区透明度、模糊度或可读性。
- 文件夹选择、保存位置和必要的确认操作可以继续使用系统原生对话框。

## 23. 反馈与错误呈现

界面按影响范围选择反馈形式，不能把所有结果都显示为 Toast。

| 形式 | 使用场景 |
|---|---|
| 内联提示 | 字段校验、格式错误和可以就地修正的问题 |
| Toast | 保存成功、后台任务完成和不阻塞当前工作的失败 |
| 页面横幅 | 当前项目、同步状态或模块级问题 |
| 阻塞对话框 | 破坏性操作、数据恢复、权限不足和需要用户选择的错误 |
| 工作区错误页 | 根目录失联、数据库损坏和无法安全继续写入 |

错误文案说明发生了什么、可能影响什么以及下一步怎么做。界面不使用“未知错误”“操作失败，请重试”等没有恢复信息的孤立文案。
